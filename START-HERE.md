This is your persistent knowledge base. It already knows who you are, your voice, your ideal client, your offers, your market, and your dreams, all pulled from your existing skills.

## How to put it on your Mac

1. Unzip this into your folder: `/Users/reneesunday/AI-Soul Sytem`
2. Open the folder in Claude Desktop (Cowork) or Claude Code.
3. When a session opens with `CLAUDE.md` present, I read it automatically and say "Soul loaded. I know who you are. What are we building today?"

## Back it up with GitHub (recommended)

1. Create a free account at github.com and install GitHub Desktop from desktop.github.com.
2. In GitHub Desktop, click "Add an Existing Repository from your Local Drive" and point it to your `AI-Soul Sytem` folder.
3. If it says the folder is not a Git repository, click "create a repository here instead," then "Create Repository," then "Publish Repository."
4. Check "Keep this code private" before publishing.
5. On a second computer, use File → Clone Repository (not Add Existing).

## The three core operations

- **Ingest:** paste a URL or say "ingest this," and I fold it into the wiki.
- **Query:** ask a question that spans pages, and I synthesize an answer with citations.
- **Lint:** say "lint" or "health check," and I fix contradictions, stale claims, and gaps.

## Daily and weekly rhythm

- Drop notes in `today.md` during the day. Say "run end of session" to file them.
- Fill in `this-week.md` during the week. Say "run my weekly Soul Update" on Sunday.
